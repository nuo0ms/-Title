# 산업연관표 분석 웹앱 (과제물1)

한국은행 2023년 산업연관표 연장표(생산자가격)를 **기본부문·소분류·중분류·대분류** 4가지 기준으로 탐색하고, 국내 생산물 최종수요 증가가 생산·수입·부가가치에 미치는 파급효과를 계산하는 웹앱입니다. Python(Pyodide)이 방문자의 브라우저에서 실행되므로 서버가 필요 없습니다.

## 사용 방법
1. 맨 위에서 **분류 기준**(기본부문 380 / 소분류 165 / 중분류 83 / 대분류 33)을 고르고 **자료 불러오기**를 누릅니다. 처음에는 Python 환경을 받느라 30초 안팎 걸리며, 다른 분류는 고르는 순간 해당 엑셀을 불러옵니다.
2. **원자료 탐색**: 시트(12개)와 행을 고르거나 검색하면 해당 행의 열별 값이 표로 나옵니다. 열도 검색할 수 있습니다.
3. **시뮬레이터**: 산업과 증가액(백만원)을 입력해 시나리오에 추가하고 **파급효과 계산**을 누릅니다. 여러 산업은 합산되며, 결과는 CSV로 내려받을 수 있습니다. 분류를 바꾸면 시나리오가 초기화됩니다.
4. **연쇄효과**: 선택한 분류 기준에서 산업별 후방·전방연쇄효과와 산업 유형을 표로 확인하고, 정렬 기준을 바꿔 볼 수 있습니다. 산점도에서 점 위에 마우스를 올리면 산업 이름과 지수가 나옵니다(가로축 후방, 세로축 전방, 로그 눈금, 점선은 지수 1).
5. **최종수요 항목별**: 산업을 고르면 소비·투자·수출 등 최종수요 항목별 생산·수입·부가가치유발액과 생산유발 비중을 표와 막대그래프로 보여 줍니다.
6. 기본부문 산업은 `classification.xlsx`(상품분류표) 기준으로 소·중·대분류 이름이 함께 표시되어 상위 분류명으로도 검색할 수 있습니다.

## 분석 방법
- 생산유발액 = 생산유발계수 L × 최종수요 증가액, 수입유발액 = 수입유발계수 M × 증가액, 부가가치유발액 = 부가가치유발계수 V × 증가액 (L = (I − Ad)⁻¹)
- 불러올 때마다 엑셀의 계수표로 L, M, V를 검증합니다(잔차 1e-8 미만이면 통과).
- 후방연쇄효과(영향력계수) = 생산유발계수표 열합 ÷ 열합의 평균, 전방연쇄효과(감응도계수) = 행합 ÷ 행합의 평균(평균=1). 두 지수가 모두 1 이상이면 전·후방 연쇄 산업, 후방만 1 이상이면 후방연쇄 중심, 전방만 1 이상이면 전방연쇄 중심, 모두 1 미만이면 독립적 산업으로 구분합니다.
- 최종수요 항목별 유발액은 엑셀의 '최종수요 항목별 생산·수입·부가가치유발액' 시트 값을 그대로 보여 주며, 생산유발 비중은 항목별 값 ÷ 최종수요계입니다.
- 한 시나리오의 총 생산유발액 ÷ 증가액 = 생산유발승수입니다.

## 단위와 자료
- 금액: 백만원(1,000백만원 = 10억원). 계수·구성비: 무차원.
- 자료: 한국은행 「2023년 산업연관표(연장표)」 투입산출표(생산자가격) 기본부문·통합소분류·통합중분류·통합대분류와 상품분류표. 공개 통계이며 개인정보는 없습니다.

## 한계
- 양(+)의 국내 최종수요 증가만 지원하며 수입 완제품 구매는 제외됩니다.
- 정적 개방모형이라 가격 변화·공급제약은 반영하지 않습니다.
- 분류별 결과는 부문을 합친 정도가 다르므로 같은 충격이라도 값이 달라집니다.
